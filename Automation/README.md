# Automation

A collection of Python-based automation tools designed for file management, backup operations, system maintenance, and DevOps workflows.

## Overview

The `Automation` directory contains practical Python utilities that automate repetitive tasks and improve productivity.

These tools are focused on:

- File management automation
- Backup operations
- Directory maintenance
- Data organization
- System administration tasks
- DevOps automation workflows

---

# Tools

## 1. File Backup

**File:**

```
file_backup.py
```

### Description

A backup automation utility that creates compressed backups from files or directories.

### Features

- Backup files and folders
- Create ZIP archives
- Add timestamps to backups
- Automate backup workflow

### Usage

```bash
python3 file_backup.py
```

---

## 2. File Organizer

**File:**

```
file_organizer.py
```

### Description

Automatically organizes files into categorized folders based on file extensions.

### Features

- Detect file types
- Create folders automatically
- Move files into categories
- Organize documents, images, videos, and archives

### Supported Categories

- Images
- Documents
- Videos
- Archives
- Code
- Other

### Usage

```bash
python3 file_organizer.py
```

---

## 3. Backup Tool

**File:**

```
backup_tool.py
```

### Description

A more advanced backup utility for creating timestamped compressed backups.

### Features

- Backup files and directories
- Generate ZIP archives
- Display backup size
- Create automated backup workflows

### Usage

```bash
python3 backup_tool.py
```

---

## 4. Bulk Renamer

**File:**

```
bulk_renamer.py
```

### Description

A tool for renaming multiple files automatically using a custom prefix and numbering system.

### Features

- Rename multiple files
- Add custom prefixes
- Automatic numbering
- Preserve file extensions

### Usage

```bash
python3 bulk_renamer.py
```

---

## 5. Directory Cleaner

**File:**

```
directory_cleaner.py
```

### Description

A cleanup automation tool that removes old files based on their age.

### Features

- Scan directories
- Find old files
- Remove files older than a selected number of days
- Automate storage cleanup

### Usage

```bash
python3 directory_cleaner.py
```


Navigate to Automation:

```bash
cd python-scripts/Automation
```

Run tools:

```bash
python3 tool_name.py
```
