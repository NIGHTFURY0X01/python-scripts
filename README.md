# Python Scripts Collection

A collection of Python-based automation, system administration, cybersecurity, networking, and DevOps utility tools.

## Overview

`python-scripts` is a personal Python utilities collection created to practice and develop practical skills in:

- Python programming
- DevOps automation
- System administration
- Network management
- Cybersecurity fundamentals
- API integration
- File management
- Monitoring

The project contains multiple categories of tools designed for real-world usage and learning purposes.

# Installation

Clone repository:

```bash
git clone https://github.com/NIGHTFURY0X01/python-scripts.git
```

Enter project directory:

```bash
cd python-scripts
```

Install dependencies:

```bash
pip3 install -r requirements.txt
```

Run any tool:

```bash
python3 folder/tool_name.py
```
