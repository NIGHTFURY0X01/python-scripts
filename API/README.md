# API

A collection of Python-based API clients for interacting with external services and retrieving dynamic data.

## Overview

The `API` directory contains Python tools that demonstrate how to communicate with REST APIs, send HTTP requests, process JSON responses, and automate data retrieval.

These tools focus on:

- REST API integration
- HTTP requests
- JSON parsing
- External service communication
- Python automation

---

# Tools

## 1. GitHub API Client

**File:**

```
github_api_client.py
```

### Description

A Python client that retrieves public GitHub user information using GitHub REST API.

### Features

- Get user information
- Display username
- Show repository count
- Show followers
- Show following
- Display profile URL

### Usage

```bash
python3 github_api_client.py
```

# Installation

Clone repository:

```bash
git clone https://github.com/NIGHTFURY0X01/python-scripts.git
```

Navigate to API directory:

```bash
cd python-scripts/API
```

Install dependencies:

```bash
pip3 install requests
```

Run tools:

```bash
python3 tool_name.py
```
